دليل مراجعة Analyse Mathématique في S1

آخر تحديث: 2026-10-13 · وقت القراءة: 8 دقائق

مادة Analyse Mathématique في السداسي الأول تعتمد على أربع مهارات تتكرر في الامتحانات: تحديد مجال التعريف، وحساب النهايات، والاشتقاق، ودراسة النقاط الحرجة. هذا الدليل يلخصها بأمثلة محلولة تستطيع إعادة حلها بنفسك.

1) مجال التعريف (Domaine de définition)

قبل أي حساب اسأل نفسك: ما الذي يمنع الدالة من أن تكون معرّفة؟ القواعد الأساسية:

  • المقام لا يساوي صفراً: 1/g(x) تتطلب g(x) ≠ 0.
  • داخل الجذر التربيعي يجب أن يكون المقدار موجباً أو منعدماً: √g(x) تتطلب g(x) ≥ 0.
  • داخل اللوغاريتم يجب أن يكون المقدار موجباً تماماً: ln(g(x)) تتطلب g(x) > 0.
  • الدالة الأسية e^x معرّفة على كل الأعداد الحقيقية.

مثال: f(x) = ln(x) / x. اللوغاريتم يتطلب x > 0 والمقام يتطلب x ≠ 0 فيكون Df = ]0, +∞[.

مثال آخر: f(x) = x·e^(−√x). الجذر يتطلب x ≥ 0 فيكون Df = [0, +∞[.

2) النهايات (Limites)

الدوال الكسرية عند اللانهاية

عند x → ±∞ أخرج أكبر قوة في البسط والمقام. إذا تساوت الدرجتان فالنهاية هي نسبة المعاملين الرئيسيين. مثال: lim (2x² − x − 1)/(x² − 1) = 2 عندما x → +∞.

حالة عدم التعيين 0/0

حلّل البسط والمقام ثم اختصر العامل المشترك. مثال: (2x² − x − 1)/(x² − 1) عند x → 1. نكتب 2x² − x − 1 = (2x + 1)(x − 1) و x² − 1 = (x − 1)(x + 1) فنحصل على (2x + 1)/(x + 1) ونهايته 3/2.

مقارنة سرعة النمو

عند +∞ تنمو الدالة الأسية أسرع من أي قوة لـ x، والقوة أسرع من اللوغاريتم. لذلك:

  • lim x·e^(−x) = 0 عندما x → +∞.
  • lim ln(x)/x = 0 عندما x → +∞.
  • lim x·ln(x) = 0 عندما x → 0⁺.

الجذور المتقاربة

للفرق بين جذرين مثل √(x²+2x) − x اضرب في المرافق (conjugué) ثم بسّط. هنا يصبح المقدار 2x / (√(x²+2x) + x) ونهايته عند +∞ هي 1.

3) الاشتقاق (Dérivées)

  • جداء: (u·v)′ = u′v + uv′. مثال: (x·ln x)′ = ln x + 1.
  • خارج قسمة: (u/v)′ = (u′v − uv′) / v². مثال: (ln x / x)′ = (1 − ln x)/x².
  • تركيب: (e^u)′ = u′·e^u. مثال: (e^(−x))′ = −e^(−x).

4) النقاط الحرجة (Points stationnaires)

الخطوات: احسب f′ ثم حلّ f′(x) = 0 داخل مجال التعريف فقط، ثم احسب f″ عند كل حل. إذا كانت f″ > 0 فهي نهاية صغرى محلية، وإذا كانت f″ < 0 فهي نهاية عظمى محلية.

مثال محلول: f(x) = x² − 2·ln(x) − 3x على ]0, +∞[.

  1. f′(x) = 2x − 2/x − 3 = (2x² − 3x − 2)/x = (2x + 1)(x − 2)/x.
  2. على المجال x > 0 الحل الوحيد هو x = 2 (لأن x = −1/2 خارج المجال).
  3. f″(x) = 2 + 2/x² وهي موجبة دائماً، إذن عند x = 2 نهاية صغرى، وقيمتها f(2) = −2 − 2·ln 2.

5) دوال بمتغيرين (Fonctions de deux variables)

المشتقة الجزئية بالنسبة لـ x تعني اعتبار y ثابتاً، والعكس صحيح. مثال: f(x, y) = e^(x·y²).

  • ∂f/∂x = y²·e^(x·y²) و ∂f/∂y = 2xy·e^(x·y²).
  • ∂²f/∂x² = y⁴·e^(x·y²).
  • ∂²f/∂x∂y = (2y + 2x·y³)·e^(x·y²).
  • ∂²f/∂y² = (2x + 4x²y²)·e^(x·y²).

النقاط الحرجة لدالة بمتغيرين: حلّ ∂f/∂x = 0 و ∂f/∂y = 0 معاً. ثم احسب r = ∂²f/∂x² و s = ∂²f/∂x∂y و t = ∂²f/∂y² وقارن r·t − s² بالصفر: إذا كانت موجبة وكان r > 0 فهي نهاية صغرى، وإذا كانت موجبة وكان r < 0 فهي عظمى، وإذا كانت سالبة فهي نقطة سرج (point selle).

مثال: f(x, y) = x² + y² − 2x − 4y. الحل: 2x − 2 = 0 و 2y − 4 = 0 فالنقطة (1, 2). هنا r = 2 و t = 2 و s = 0 فيكون r·t − s² = 4 > 0 ونهاية صغرى.
